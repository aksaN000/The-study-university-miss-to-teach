# Practice

The book explains and demonstrates each concept; this folder is for doing something with it
afterward.

## Structure

- **`exercises/<part>/ch<NNN>-<slug>.md`**: five short prompts per chapter, for right after
  that chapter's live session. Format: `exercises/TEMPLATE.md`.
- **`assignments/<part>.md`**: one synthesis task per part, written once every chapter in
  that part is complete. Format: `assignments/TEMPLATE.md`.
- **`exams/<part>.md`**: closed-book, from-memory checkpoints per part, written after that
  part's assignment. Format: `exams/TEMPLATE.md`.
- **`solutions/`**: mirrors the three folders above as real content is written. Attempt
  first.

## Status and numbering

A skeleton, generated from the book's syllabus by `tools/generate_practice_skeleton.py`, so chapter and part numbers always match the book. Real content is added
only after the matching material has actually been taught, practiced hands-on, and passed a
recall check. Regenerating never overwrites a file that holds real content.
